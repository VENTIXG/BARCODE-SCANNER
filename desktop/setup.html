Server της εταιρείας

Για πολλούς υπολογιστές: όλοι βλέπουν και ενημερώνουν τα ίδια δεδομένα, ζωντανά.

Μόνο αυτός ο υπολογιστής

Τα δεδομένα μένουν σε αυτόν τον υπολογιστή, χωρίς server. Κατάλληλο για ένα σημείο εργασίας.

Σε αυτόν τον υπολογιστή υπάρχουν ήδη δεδομένα: θα τα βρείτε όπως τα αφήσατε.

Τα δεδομένα αυτού του υπολογιστή δεν μεταφέρονται μόνα τους στον server. Για μεταφορά: στην τοπική εφαρμογή Ρυθμίσεις → Αντίγραφα ασφαλείας → «Λήψη» του πιο πρόσφατου, και στον server Ρυθμίσεις → Αντίγραφα ασφαλείας → «Επαναφορά από αρχείο».
